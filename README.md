I build **high-traffic digital platforms with Go and Next.js**, and bring **AI into the day-to-day work** of engineering teams.

Senior Full Stack Developer with 5+ years in frontend and 3 years leading full stack solutions. I work remotely for international companies on **Arc XP**, powering news and media sites in Peru and Paraguay such as **Trece, Unicanal, La Tribuna, Crónica and Depor** (Grupo El Comercio).

## Highlights

- **Multi-tenant Arc XP components** in React and TypeScript, cutting time-to-market for new sections by **25%** across several newspapers.
- **Django to Go microservices** for depor.com's live football results API, with **20% faster** responses during traffic peaks.
- **Real-time sports data feeds** built with Go channels and cron jobs, raising user engagement by **30%**.
- **Email microservice in Go** that processes and stores messages for several platforms, taking load off the main architecture.
- **Core Web Vitals and SEO** work that grew organic search traffic by **35%**.
- **GraphQL APIs** that let front-end clients fetch only the data they need.

- **Spec-Driven Development (SDD)** and **Observation-Driven Development (ODD)** for AI-assisted delivery.
